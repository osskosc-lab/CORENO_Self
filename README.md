# CORENO Self

**CORENO Self** is a falsification-first research program for testing an access-relative, history-dependent boundary-update model of self.

## Current scientific status

**G — INSUFFICIENT_EVIDENCE**

The repository currently contains a theoretical/methodological proposal and a synthetic qualification program. A passing synthetic qualification does **not** establish claims about human selfhood, consciousness, qualia, soul, Buddhism, or post-mortem personal continuity.

## Core operational idea

The model treats selfhood as a history-dependent boundary-update process rather than assuming an invariant core:

```text
B_(t+1) = F(B_t, O_t, H_t, I_t, E_t, U_t)
```

Phase 0A v1.1 separates:

- information-set diagnostics from structural evidence,
- component necessity from input destruction,
- history-order intervention from predictor-input shuffling,
- coherent access-relative observation from label-only swaps,
- update-law distance from causal/lineage continuity.

## Research gates

The current authorized gate is:

**Phase 0A v1.1 — Minimal Synthetic Qualification**

Technical smoke testing may establish that the pipeline executes. Only the frozen 64-seed run may change the scientific qualification status.

## Claim firewall

This repository does not claim to prove:

- an invariant core does not exist in nature,
- human selfhood is explained,
- consciousness or qualia are explained,
- latent states are directly measurable in humans,
- souls or afterlife exist,
- history acts without a present physical/informational carrier.
